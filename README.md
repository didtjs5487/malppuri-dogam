# 말뿌리 도감

낱말과 지명의 뿌리를 식물·동물 도감처럼 채집하는 웹 앱이에요. 우리말 어원, 헷갈리는 맞춤법, 인천 지명 유래를 카드로 모아요.

## 구성

- `index.html`: 화면과 동작 (도감 · 사전 · 지도 · 채집하기, 내 노트)
- `data/`: 카드 데이터 (분야별 파일)
  - `roots.js`, `hanja_words.js`, `myths.js`, `hanja_chars.js`, `spelling.js`, `rules.js`: 낱말 카드
  - `places.js` ~ `places5.js`: 인천 지명 카드 (지명과)
  - `verified.js`, `refs2.js`: 표준국어대사전·한글 맞춤법과 대조한 목록과 근거 문구
- `icons/`, `manifest.webmanifest`: 앱 아이콘과 홈 화면 설정
- `photos/`, `data/photos.js`: 지명 카드 사진과 출처

## 카드 등급

- **확정**: 사전이나 기록으로 확인되는 유래
- **통설**: 널리 받아들여지지만 단정은 어려운 풀이
- **속설 주의**: 널리 퍼졌지만 근거가 약한 이야기

낱말 카드의 근거는 표준국어대사전, 지명 카드의 근거는 인천광역시 누리집 「지명유래」(2002년도 인천광역시사)예요.

## 사진

지명과 카드 가운데 일부에는 사진이 들어 있어요. 사진 파일은 `photos/`에 있고 카드 번호가 파일 이름이에요. 어느 카드에 어떤 사진을 쓸지는 `data/photos.js`에 적고, 작가와 이용 조건은 카드 화면과 [`photos/CREDITS.md`](photos/CREDITS.md)에 함께 보여 줘요.

- 위키미디어 커먼스 사진(CC BY, CC BY-SA, CC0, 퍼블릭 도메인)은 화면에 맞게 크기만 줄였어요.
- 인천시 「사진으로 보는 역사」 사진은 공공누리 제4유형(출처표시·상업적 이용 금지·변경 금지)이라 원본 그대로 실었어요.
- 새 사진을 넣을 때는 이용 조건을 먼저 확인하고, 쓸 수 있는 것만 넣어요.

## 실행

서버 없이 `index.html`을 열면 돼요. 글꼴과 아이콘은 인터넷에서 받아 와요. 내 노트와 채집 기록은 이 기기의 브라우저에만 저장돼요.
